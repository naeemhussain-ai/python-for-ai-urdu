# Module 5: Notebook se asli project

Ab code Colab se nikal kar apne computer par: VS Code + uv. Expense Tracker do files mein bant gaya:

- `main.py`: program yahan se chalta hai
- `expenses.py`: kharche ke functions (`ask_expense`, `format_rs`, `total`, `print_report`)

## Chalane ka tareeqa

1. [uv install karo](https://docs.astral.sh/uv/getting-started/installation/)
2. Is folder mein terminal kholo
3. Chalao:
   ```
   uv run main.py
   ```

Kharcha likho aur Enter dabao. Khali Enter dabane se program band ho jata hai aur report aati hai.
