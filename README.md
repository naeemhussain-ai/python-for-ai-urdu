## Colab notebooks kaise use karein

1. **Open in Colab** button dabao.
2. Colab mein upar **Copy to Drive** dabao. Warna aap ke changes save nahi honge.
3. Har cell **Shift + Enter** se chalao.

## Local modules (5–10) kaise chalayein

1. [uv install karo](https://docs.astral.sh/uv/getting-started/installation/).
2. Module ke folder mein terminal kholo.
3. `.env.example` ho to us ki copy banao aur naam `.env` rakho.
4. `uv run main.py`

Har module ka folder apne aap mein poora hai: pichle module ka code + is module ka naya kaam.
