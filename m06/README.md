# Module 6: Files, JSON aur `.env`

Ab kharche `expenses.json` mein save hote hain, is liye program band karne par bhi gum nahi hote. Rozana ki limit `.env` file se aati hai.

## Chalane ka tareeqa

1. `.env.example` ki copy banao aur naam `.env` rakho
2. `.env` mein apni limit likho, jaise `DAILY_LIMIT=8000`
3. Chalao:
   ```
   uv run main.py
   ```

`expenses.json` pehli dafa chalane par khud ban jati hai. `.env` GitHub par nahi jati (`.gitignore` mein hai).
